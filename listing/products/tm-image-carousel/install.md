In Qlik Cloud, upload the extension zip in the Management Console, then add Tm Image Carousel from Custom objects to a sheet. Add a picture field first; captions, alt text, links, previews and an optional value can follow. Set On image click to Open large when viewers need a picture-sized view; right-to-left apps mirror navigation automatically. Pictures from the app media library need no admin change. Web pictures need the picture site allowed in the tenant's image Content Security Policy.
