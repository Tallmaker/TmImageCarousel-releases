## New

- **Open large** opens a picture in a large window with Previous, Next, Close and zoom controls. Escape closes it and returns focus; in Gallery it replaces click-to-select. Off by default.
- Right-to-left apps mirror the carousel: Previous is on the right, Next on the left, and keys, swipes, slides and the gallery grid follow the reading direction.
- In edit mode, an author hint counts pictures with neither alt text nor a caption so they can add screen-reader descriptions. Viewers do not see it.

## Changed

- The extension appears as **Tm Image Carousel** in Qlik's extension list instead of **TmImageCarousel**. Saved charts continue to work.

## Fixed

None in this release.
