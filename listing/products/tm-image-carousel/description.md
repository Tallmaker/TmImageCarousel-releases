Tm Image Carousel turns rows in a Qlik app into a browsable set of pictures. Show one image at a time with a preview strip, or scan a scrolling gallery and select items in place. Add captions with formatted values, picture descriptions and links; formulas can supply image or text values. Viewers can zoom in or use clicks to select an item, open a link or move to a sheet, while Qlik selections keep the view relevant. Styling follows the sheet theme, and edit mode points authors to missing click destinations. It is tested on Qlik Cloud; client-managed Qlik Sense is untested.
